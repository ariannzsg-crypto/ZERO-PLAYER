# Screenshots

No device screenshots are committed to this repository yet — they are captured from the running
application so that nothing shown here is a mockup.

Capture the primary screens with adb and drop the PNGs in this folder:

```bash
adb exec-out screencap -p > docs/screenshots/01-home.png
adb exec-out screencap -p > docs/screenshots/02-library.png
adb exec-out screencap -p > docs/screenshots/03-album.png
adb exec-out screencap -p > docs/screenshots/04-now-playing.png
adb exec-out screencap -p > docs/screenshots/05-equalizer.png
adb exec-out screencap -p > docs/screenshots/06-lyrics.png
```

Recommended: a 1080 × 2400 (or larger) device in dark mode with the default ZERO PLAYER theme.
